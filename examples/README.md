# Examples

Two real Reels written in the STACK style. Each file is a project's `video.ts` (scene table + beats). They reference `shots/*` screenshots and a `words.ts`
transcript that belong to those projects and are not included: use them as a reading guide, not as runnable projects. Start from `daily/video-template.ts` instead.

- `reel-04-wisefunnel-mcp.video.ts`: headline captions only, theme `cream`
- `reel-06-skillithub.video.ts`: small live caption, theme `white`, real result on screen (`winShot`, `fork`, `answer`)

The product names in the examples (WiseFunnel, Skillithub) belong to the author's own products and are used only as example content.
